# Frezja Studio

Landing page estática em português brasileiro. Os arquivos prontos para hospedagem estão em `dist/`.

Para visualizar localmente: `python -m http.server 4173 --directory dist` e abra `http://localhost:4173`.

O telefone e a mensagem de agendamento são centralizados em `dist/script.js`. Instagram: https://www.instagram.com/frezjastudio/.

Foram utilizadas apenas as duas imagens reais fornecidas. A fotografia pode ser ampliada no portfólio. A seção de cuidados evita anunciar técnicas, preços ou serviços específicos sem confirmação.

Não há formulário, armazenamento de dados ou cookies de rastreamento. As fontes são Cormorant Garamond e Manrope, servidas pelo Google Fonts.
